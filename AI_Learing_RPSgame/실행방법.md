# 실행방법

## 구성 파일

- `EX_03_Board_RPS_PreTrained_YOLO26.py`: 카메라 기반 2인 가위바위보 게임
- `best_float32_26_2.tflite`: 게임에서 사용하는 YOLO26 TFLite 모델
- `requirements.txt`: Python 패키지 목록

스크립트와 모델 파일은 같은 디렉터리에 있어야 합니다. 스크립트는 기본 카메라 장치 `0`을 사용합니다.

## 설치 및 실행

Python 3.11 환경을 권장합니다. 프로젝트 디렉터리에서 패키지를 설치하고 게임을 실행합니다.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python EX_03_Board_RPS_PreTrained_YOLO26.py
```

Raspberry Pi에서 `tflite-runtime` 설치가 실패하면 Python 버전과 CPU 아키텍처에 맞는 LiteRT wheel을 설치한 뒤 다시 실행합니다.

## 게임 플레이 방식

1. 실행 창에서 스페이스바를 눌러 게임을 시작합니다.
2. 왼쪽 플레이어는 카메라 화면의 왼쪽, 오른쪽 플레이어는 오른쪽에 손을 보여줍니다. 양쪽 손이 모두 인식되면 `RECOGNITION COMPLETE`, `READY?`, `START!` 안내가 차례로 나옵니다.
3. `SCISSORS`, `ROCK`, `PAPER` 카운트가 각각 표시됩니다. 판정이 끝날 때까지 손 모양을 유지합니다.
4. 판정 순간의 카메라 사진이 약 3초간 고정 표시됩니다. 사진 위의 파란색 `LEFT`와 빨간색 `RIGHT` 배지 및 아래쪽 선택 표시에서 각 플레이어가 낸 모양을 확인할 수 있습니다.
5. 결과 화면이 끝나면 다음 라운드로 자동 진행됩니다. 총 3라운드이며, 무승부는 결과만 표시하고 점수에는 더하지 않습니다.
6. 마지막 라운드가 끝나면 최종 승자가 표시됩니다. 스페이스바를 누르면 점수를 초기화하고 다시 시작하며, `q` 키를 누르면 종료합니다.

## 조작 키

- `Space`: 게임 시작 또는 최종 결과 후 재시작
- `Q`: 게임 종료
